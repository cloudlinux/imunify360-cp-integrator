# Agent entry point

When the user asks you to integrate Imunify360 with a hosting control panel it does not
support natively (write `integration.conf` and its scripts, or validate such an
integration on a server), read [`skills/cp-integrator/SKILL.md`](skills/cp-integrator/SKILL.md)
and follow it. Paths it gives relative to "this skill" mean `skills/cp-integrator/`.

Not for cPanel, Plesk or DirectAdmin, which Imunify360 supports directly.
